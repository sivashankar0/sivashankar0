## 🚀 Projects

### 📱 College QR Attendance
A full-stack attendance system: teachers show a rotating QR code, students scan it and pass a server-side face check.
- **Backend:** FastAPI + PostgreSQL, OpenCV YuNet/SFace face verification, signed rotating QR tokens, geofencing, refresh-token rotation, audit log
- **Mobile:** one React Native (Expo) app for students, teachers, admins and biometric officers
- Face templates are encrypted (AES-256-GCM); no raw images are stored

🔗 https://github.com/sivashankar0/qr-attendance

### 🧾 OCR Bank Statement Extraction & Visualization
Extracts and visualizes financial data from scanned documents (balance sheets, P&L statements, payslips).
- Fetches document images from Cloudinary and runs them through Tesseract OCR
- Parses fields like Revenue, Expenses, and Net Profit using regex / GPT-2
- Visualizes results as bar or pie charts through an interactive Gradio interface
- Exports processed data as CSV, plus a ZIP of the source images

🔗 https://github.com/sivashankar0/Ocr_Bank_Statment

### 🍅 Tomato Plant Disease Detection
A trained image-classification model that detects disease in tomato plant leaves from photos.
- Built and trained in a Jupyter Notebook

🔗 https://github.com/sivashankar0/Tomato_Plant_Disease_detection
